# Start Frontend (Local Dev)

Run this to start the Next.js frontend on port 9002.

```bash
npm run dev
```

**What this does:**
- Starts Next.js 15 with Turbopack (faster bundler)
- App available at: http://localhost:9002
- It talks to the backend at http://localhost:8000/api/v1 (set in .env.local)

**Prerequisite:** Backend must be running first (use /start-backend)
